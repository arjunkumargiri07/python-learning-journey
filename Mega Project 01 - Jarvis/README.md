# 🤖 Jarvis – Voice Activated Virtual Assistant

Jarvis is a **Python-based Voice Activated Virtual Assistant** capable of understanding voice commands, responding with speech, opening websites, playing music, reading news, and answering questions using OpenAI GPT models.

This project combines **Speech Recognition, Text-to-Speech (TTS), Web Automation, APIs, and Artificial Intelligence** to create an intelligent desktop assistant similar to **Alexa, Google Assistant, or Siri**.

---

## 🚀 Features

- 🎤 Voice Recognition using `speech_recognition`
- 🗣️ Text-to-Speech using `pyttsx3`
- 🌐 Open websites using voice commands
- 🎵 Play music from an online music library
- 📰 Read the latest news headlines using NewsAPI
- 🤖 Answer questions using OpenAI GPT
- 🔁 Wake-word detection ("Jarvis")
- 💬 Natural voice interaction

---

# 📌 Project Workflow

### 1️⃣ Initialization

When the program starts, Jarvis greets the user:

```
Initializing Jarvis...
```

---

### 2️⃣ Wake Word Detection

Jarvis continuously listens for the wake word:

```
Jarvis
```

Once detected, it responds:

```
Ya.
```

---

### 3️⃣ Command Processing

Jarvis recognizes voice commands and performs tasks such as:

- Open Google
- Open YouTube
- Open Facebook
- Open LinkedIn
- Play music
- Read today's news
- Answer general questions using AI

---

### 4️⃣ Speech Output

Jarvis replies using speech generated by:

- `pyttsx3` (Offline)
- `gTTS` + `pygame` (Online)

After completing a task, it returns to listening for the next wake word.

# ▶️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/Jarvis-Voice-Assistant.git
```

Navigate to the project folder:

```bash
cd Jarvis-Voice-Assistant
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

---

# ▶️ Running the Project

Start Jarvis by running:

```bash
python main.py
```

Jarvis will initialize and wait for the wake word.
