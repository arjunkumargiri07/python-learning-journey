# 🎯 The Perfect Guess Game

A simple Python number guessing game where the computer generates a random number, and the player tries to guess it using hints.

## 📌 Project Overview

**The Perfect Guess** is a beginner-friendly Python project that demonstrates the use of:

- Random number generation
- Loops
- Conditional statements
- User input
- Counting the number of attempts

The game continues until the player correctly guesses the randomly generated number.

---

## 🚀 Features

- 🎲 Generates a random number automatically
- ⌨️ Accepts user guesses
- 📉 Displays **"Lower number please"** if the guess is too high
- 📈 Displays **"Higher number please"** if the guess is too low
- ✅ Congratulates the player on a correct guess
- 🔢 Shows the total number of guesses taken
